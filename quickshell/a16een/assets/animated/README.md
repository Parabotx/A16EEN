# A16EEN Animated Wallpapers

Place animated wallpapers that ship with A16EEN here:

```
quickshell/a16een/assets/animated/
```

Planned supported formats:

- GIF
- MP4
- WebM
- MOV

The animated wallpaper system will use the appropriate Qt media renderer for each format.

Keep built-in animated wallpapers reasonably sized and encoded for desktop playback. Very large or high-frame-rate videos can increase CPU/GPU usage.

Personal animated wallpapers belong in:

```
~/Pictures/a16een/animated/
```

A16EEN updates will not overwrite the user's animated wallpaper collection.

Animated wallpapers are a separate collection from static wallpapers so the picker can clearly distinguish images from motion backgrounds.
