# A16EEN Built-in Wallpapers

Place wallpapers that ship with A16EEN here:

```
quickshell/a16een/assets/wallpapers/
```

Use any supported static image format:

- PNG
- JPG / JPEG
- WEBP
- BMP
- TIFF / TIF
- TGA
- SVG
- PPM / PGM / PBM
- XPM / XBM

The filename does not need to follow a naming convention. A16EEN displays the actual filename in the wallpaper picker.

The required first-launch default is:

```
default.png
```

Personal wallpapers belong in:

```
~/Pictures/a16een/
```

Animated wallpapers and short-video backgrounds will be added in a later stage.
