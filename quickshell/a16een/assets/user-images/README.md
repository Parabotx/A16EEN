# User image folder

This directory is a template marker for A16EEN's user-managed visual assets.

On an installed system, the persistent wallpaper folder is:

`~/.local/share/a16een/assets/images/wallpapers/`

Put PNG, JPG, JPEG, or WEBP wallpapers there.

Use:

```sh
a16een wallpaper list
a16een wallpaper set my-wallpaper.png
a16een wallpaper next
a16een wallpaper previous
a16een wallpaper reset
```

User wallpapers are kept outside the A16EEN source/runtime tree so updates do not overwrite them.
