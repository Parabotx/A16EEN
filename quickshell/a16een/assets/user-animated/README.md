# User Animated Wallpapers

This directory is a repository template marker only.

On an installed A16EEN system, personal animated wallpapers will live in:

```
~/Pictures/a16een/animated/
```

Put your own GIF, MP4, WebM, or MOV wallpaper files there.

The wallpaper picker will discover these files automatically once animated wallpaper support is enabled.

User media is intentionally stored outside the A16EEN runtime/source tree so updates cannot overwrite personal wallpapers.
